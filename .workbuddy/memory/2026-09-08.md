# 2026-09-08

## 测试阶段（用户已授权 Accessibility + Input Monitoring）

上一轮把"推倒重来"重写的代码编译通过、单测通过并打了 tag v0.3.31。本轮负责实际测试。

### 做了什么
- 新增 `#[cfg(test)]` 注入/光标 seams：
  - `src/capture.rs` 的 `cursor::hide/show/park` 在 test 下为 no-op（不碰 WindowServer）。
  - `src/input.rs` 的 `apply_input` / `warp_cursor` + `simulate`/`EventType` 在 test 下为 no-op（不碰真实输入设备）。
  - `src/diag.rs` 的 `log` 在 test 下为 no-op，避免测试把 HAND-OFF/RETURN 写进用户真实的 `mouseshare.log`。
- 新增端到端集成测试 `src/control.rs::integration`：用**真实 TCP**（primary hub + secondary client over 127.0.0.1）+ 真实 `GrabCtx`/`on_capture`/`on_enter_screen`/`on_secondary_input` 跑通完整跨屏状态机。4 个用例：handoff_over_tcp、cooldown_blocks_recross、held_keys_released_on_leave、hotkey_enters_first_remote。
- 测试发现并修正一处**真实 bug 的回归风险**：`Ctrl.local_bbox` 由 main.rs 启动时从 own_layout 填充（已正确）；集成测试最初用 `Ctrl::default()` 漏填，导致 `on_enter_screen` 早退、次级收不到控制——已在测试中复刻 main.rs 的填充逻辑。这同时确认 main.rs 的接线是对的。
- 修正我的测试断言：次级进入边缘是 `EnterScreen` 的**对向边**（primary 从 Right 越界 → 次级在 Left 边 seed `bl+2`），不是 `br-1`。最终断言 vx=102（seed 2 + delta 100）。

### 结果
- `cargo test`：**12 passed; 0 failed**（8 单测 + 4 集成）。
- `cargo build`：0 error。
- 用户真实 `mouseshare.log` 证据：40× HAND-OFF->B、34× RETURN、6× ENTER<-primary side=Left seed=(2,540)、0 error、0 tap disabled —— 说明 macOS 上 CGEventTap 稳定、跨屏交接真实可用，且与集成测试断言完全一致。
- 已清空被测试污染的 diag log，提交 v0.3.32。

### 可复用经验（headless 测 GUI 程序）
- agent 跑在用户 Mac 上但**无 GUI session**（SECURITYSESSIONID 为空），egui 窗口无法渲染。对策：用真实 TCP 传输 + 真实控制层做端到端逻辑测试（注入/cursor/diag 全部 no-op seam），不依赖显示。
- 集成测试必须用 `connect_client` 后**主动发 Hello**，否则 hub 永不注册 peer（Hello 由 app 在 connect 后发送，connect_client 本身不发）。
- `cargo test` 默认并行，多个用例同时 handoff 会在共享 diag log 产生重复行——用 cfg(test) 关掉 diag 写入即可。
