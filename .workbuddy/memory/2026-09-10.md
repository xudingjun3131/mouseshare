
## v0.7.0 (11:30) — 扁平化 UI 重做

用户反馈：截图红色框标注了顶栏水平带 + 侧栏左侧一条空白竖条，说"出现了很多无聊的框子，保持功能，UI重做"。

**主要改了三件事：**

1. **删掉顶栏 TopBottomPanel**：原来顶栏有重复的 "MouseShare" 文字 + 状态指示 pill + 一条 hairline。在 macOS fullsize content 下整块看起来就是个无用框。整块删掉。

2. **把状态 pill 和语言 chip 挪到侧栏底部**：现在侧栏底部从下往上依次是 Quit → hairline → 中文/English → hairline → 状态 pill，紧凑的一列。

3. **去掉所有 card 框（fill + stroke）**：`card()` / `card_header()` / `card_body()` / `card_footer()` 全部退化为纯留白 + 排版。章节靠标题字号和留白分组，不再靠填色圆角框。"My Role"、"Primary setup"、"Screen layout" 这些卡片从视觉上消失，但功能完全不变。

**page_header** 也瘦身：不再带 trailing 参数（语言 chip 已经在侧栏底部），就只是 28pt 大标题 + 13.5pt 副标题 + 28pt 间距。

**验证**：26/26 测试通过；osascript 这台机器权限掉了没法做合成点击测试（v0.6.2 时已经掉了），但改动纯渲染层，不动控制流，行为不变。CI 三平台全绿，5 个安装包齐全。

**经验**：用户反复说"框子太多"的时候，先看哪些是装饰性的（fill + stroke）、哪些是功能性的（hover bg、active bg）。装饰性的直接砍，功能性的保留——nav_item 的 hover/active 反馈就是这种，没动。card 框完全是装饰。

**遗留**：本次重做保留了 sidebar 的 hairline 右边线（结构性分隔，不是装饰），以及 nav_item 自身的 hover/active 圆角（功能反馈）。下一步如果用户还要更激进，可以再去掉右边线、把 sidebar 改成透明。
